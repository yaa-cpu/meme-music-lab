# 梗图音乐坊 · Meme Music Lab

一个纯前端梗图打击垫与线谱音乐实验。梗卡、普通乐器、原创自动底奏、自由滑轨、边弹边录、人声、独立混响与卡带图鉴均在浏览器本地运行。

## 本地启动

需要 Node.js 18 或更新版本，无需安装第三方依赖。

```bash
npm run dev
```

终端会显示本地预览地址。也可以用任意静态 HTTP 服务器托管本目录；不要直接通过 `file://` 打开，否则音频读取可能受浏览器限制。

## 当前功能

- 首页 2 × 2／3 × 3 梗图打击垫：鼓面固定 1:1，只放按键，预设、底奏、换装、布局切换等控制条移到鼓面外；支持数字键 1–9。
- 鼓面按键之间的所有空隙都铺有灯带：底鼓、军鼓、踩镲、贝斯、和弦分别点亮不同的灯格并留下余辉，敲击时还会从按键向外扩散。
- 按键图案使用透明抠图，按键本身不动，图案由节拍驱动跳舞：底鼓跳、军鼓甩头、踩镲颠、贝斯压扁、和弦扭身，四种舞步按按键轮换，敲击时再给一记大力弹跳。
- 每次敲击触发命中特效：按键白色过曝闪光、冲击波圆环、八角星迸发、14 条放射反馈线、拖尾火花（方块/三角/星形/菱形/闪光）、闪电、牌面泛光与短促震动，光会沿矩阵传给相邻按键，并弹出拟声词。
- 敲击和底奏还会在首屏背景里飘出 SVG 图标（音符/八分音符/星/闪电/心/火焰/爪印/王冠/猫头/太阳/气泡/骰子等 22 种）。
- 页面背景会随底奏每 4 小节轮换一种全屏样式（同心环 / 波浪带 / 放射光芒 / 点阵 / 几何纸屑），底鼓推动光晕、军鼓改变振幅，敲击还会额外溅出纸屑。
- 页面背景与卡片装饰也会跟着底鼓／军鼓做呼吸闪动。
- 梗采样和乐器统一映射到 C 大调五声音阶；首次敲击自动启动底奏，也可手动关闭。
- 底奏是独立的自动伴奏，不属于按键分类：116 BPM 十六分音符网格、四踩底鼓 + 反拍军鼓 + 切分贝斯 + 和弦 / 踩镲铺底，四小节一循环并带过门，音量与压缩独立于按键。
- 走进线谱或演奏区时底奏自动暂停，回到打击垫敲一下自动续上。
- 打击垫采样区间固定、不随机切段：每个按键从裁剪后的起点播放；**短按最多放到 0.2s；按住多少就播多少，播到采样结尾还在按会自动循环，松开立刻停**（玩家决定时长，没有固定的长按预设）；按住期间有持续的脉冲光晕、循环光圈、火花/灯带/背景节拍反馈；快速连击时直接掐掉上一声、立刻重新触发（6ms 消咔哒）；不同按键用各自的音符改变 pitch。卡准底奏拍子时冒出「完美 / 不错」气泡并累计连击。
- 三套原创底奏由独立编曲引擎（`src/pad-grooves.js`）驱动，对照真实 DJ remix 的响度/频段/律动基准设计：柑橘跳跳糖 124 BPM Disco-Funk House、像素弹跳 134 BPM 2-step/Speed Garage、夜空气泡 86 BPM Lo-fi Half-time；16 小节结构含 intro／build／drop／breakdown／过门，带侧链泵动、段落滤波与 impact／riser 段落动作。不使用参考玩具的音频或循环。
- 打击垫背包可将每键替换为梗采样、乐器或鼓点，并可命名、保存和删除自定义预设。
- 4／5／8 音阶双排操作台，以及 12／24／49／61／88 键半音阶钢琴操作台。
- 自由时间轴：点击并右滑放入与延长音符，拖动调整位置，音符可独立设置混响。
- 全屏落键录制、长按音符、粒子反馈、麦克风人声和手动回滚重录。
- 点左侧音阶名选中轨道，一键把线谱片段合成为「loop 底奏卡带」；卡带像音符一样摆在音序器底部固定的 3 条卡带轨上（最多占 3 行谱面高），可横向拖动位置、换轨叠放，播放时按播放头触发。
- 梗采样卡带、乐器卡带和本地任务图鉴。音符卡带扩展为 9 盒：4 盒梗采样 + 5 盒按 ACE Studio 音源分类整理的流行乐器包（弦乐组／铜管与木管／键盘与合成／吉他与拨弦／鼓组与贝斯）。合成器已重构为**预设驱动**：`src/synth-engine.js` 用数据描述振荡器层／噪声层／滤波包络／ADSR／力度响应／颤音，共 **36 个音色预设**（键盘 7、弦乐 7、铜管 4、木管 5、吉他拨弦 5、贝斯 2、合成器 5、鼓组 1），新增音色只需加一条预设数据。
- **独立 ML 转录环境**：工作区 `_shots/venv_bp`（Python 3.11 + basic-pitch 0.4.0 / TensorFlow 2.15，走清华 PyPI 镜像安装）；`_shots/run_basicpitch.py` 对钢琴/吉他/其他分轨做复音转录，`_shots/post_basicpitch.py` 做调性与和弦吸附，再进工程包。\n- **鼓组混响与键位**：鼓组轨的 room 混响从 4% 提到 **18%**（现在能明显听到空间感）；鼓组键位：C4/C5=底鼓、B4/D4=军鼓（军鼓加厚了鼓皮和响弦、尾巴约 120ms）、F4=通鼓、E4=踩镲、G4=开镲。
- **鼓组改为电子鼓机音色（808/909 方向）**：底鼓=110→46Hz 音高下坠 + 短点击 + 48Hz 低频鼓腔；军鼓=双音鼓皮 + 短响弦 + 高频瞬态；踩镲=金属方波簇（6.4k/9k/12k）过 7kHz 高通，全部短衰减、没有白噪声尾巴；去掉拍手层。目标是"干净的鼓机"，不再追真实鼓组。
- **按 ACE 实际节拍网格对齐**（"各弹各"的根因）：原来工程用 129.89 BPM、窗口从 29.57s 切，而 ACE 对原曲的节拍分析是 **129.795 BPM、第一个 downbeat 在 0.2s、29.74s 处是真实小节线**——旧窗口比小节线早了 0.17s，导致鼓/贝斯/和弦/旋律各自落在错误的网格相位上。现在所有分轨都按真实 downbeat 重新切窗、重新转录，工程 BPM 用真实值 129.795（滚轮显示最近的 130，播放用真实值）。
- **鼓组音色重做**：kick 改成音高下坠鼓皮 + 56Hz 低频鼓腔 + 鼓槌点击三层并过轻微饱和/压缩，snare 改成鼓皮双音 + 响弦噪声 + 高频瞬态，hat/openhat 换成高通+带通噪声，避免"沙沙"的噪声感；踩镲电平提高约 1.8 倍。
- 低音与混响修正：`subBass` 预设重做（基频移到可听区、增加二倍频与谐波、增益 1.25），贝斯轨增益 1.3、底鼓加厚；所有旋律轨统一 `plate` 混响（钢琴/吉他/Pad/Lead 12%、10%、12%、12%+延迟），鼓组 `room` 8%，贝斯干声——每条轨内部混响完全一致，不再"每个音一个空间"。
- chroma 转录的钢琴/吉他/其他先按 **A 大调 + 每小节和弦音** 吸附（`bar_chords`），去掉调外音与重复叠音，解决"听感奇怪"；钢琴改用可靠的扒谱和弦铺底。
- 《生日快乐》《一闪一闪亮晶晶》《虫儿飞》使用 49 键多轨谱面，将主旋律、伴奏和低音逐音合成，不直接播放参考原曲。

## 项目结构

```text
index.html              页面结构与弹窗
src/main.js             线谱、音频、卡带、打击垫声学与播放逻辑
src/synth-engine.js     预设驱动的分层合成器（36 个音色预设，含鼓组音高映射）
src/pad-stage.js        首页打击垫、背包换装与自定义预设
src/pad-stage.css       打击垫及背包的响应式样式
src/pad-fx.js           首页打击垫的命中特效画布（冲击波、火花、闪电）
src/pad-leds.js         首页鼓面空隙里的灯带（随底奏节拍与敲击反馈）
src/pad-bg.js           首页背景的节拍样式层（同心环、波浪、放射、点阵、纸屑）
src/pad-grooves.js      底奏编曲引擎（16 小节编排、swing、段落动作，纯逻辑可在 Node 里测）
assets/cut/             打击垫按键用的透明抠图
src/music-data.js       音阶、乐器、示范曲与钢琴键布局
src/record-stage.js     全屏落键录制界面
src/style.css           桌面与移动端样式
assets/                 梗图和应用内裁剪采样
采样音频/               用户提供的源音频与裁剪片段
server.mjs              本地静态开发服务器
CREDITS.md              素材来源说明
```

## 数据与隐私

作品、设置和图鉴任务状态保存在当前浏览器 `localStorage` 的 `meme-music-lab-v1` 中；首页打击垫自定义预设使用独立键 `meme-pad-stage-v1`。数据不会自动同步到其他设备或协作者，清理浏览器数据会删除这些本地状态。麦克风人声只在用户主动授权后录制。

## 协作约定

- 默认分支为 `main`，新功能请从独立分支提交。
- 不提交 `.env`、依赖目录、临时分析音频、测试截图或本机编辑器配置。
- 提交前至少执行：

```bash
node --check src/main.js
node --check src/pad-stage.js
node --check src/music-data.js
node --check src/record-stage.js
```

- 修改界面后，在浏览器检查控制台、网络请求及 375px 窄屏布局。
- 素材权利与来源见 `CREDITS.md`。参考歌曲仅用于核对谱面，不要提交临时下载的参考分析文件；用户提供的源采样按现有目录管理。
