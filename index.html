QUICK START

三步，作出第一首抽象曲

  1. 1
    选音色

    滑动左侧滚轮切换六盒卡带：抽象梗、大狗叫逐音、两盒哈基米逐音、键盘与弦乐、管乐与电子。每盒音符数量不限；点击卡片或用卡片所示字母键选中，十三种乐器也可直接选用。保留 4／5／8 双排音阶，也可切换 12／24／49／61／88 键钢琴操作台。

  2. 2
    滑出音符

    在空白轨道按下并向右滑，一次完成放入和延长；位置与长度不吸附格子，时间轴会随乐曲自动增长。拖动音符可精细移动，[ / ] 以 0.25 步微调。点击音符后，三枚圆形按钮会短暂悬浮在上方：混响预设、干湿比例与删除；前两个直接上下拖动，无操作约 3 秒自动隐藏。

  3. 3
    边弹边录

    点击进入全屏落键模式。每按一下，谱面按当前 BPM 向前滚动一步；连续熟练弹奏时便形成匀速滚动，不按则停下等待。点按或长按数字键、落键轨道与底部音阶，松开后按真实时长收尾，并伴随粒子反馈。尾音结束不会退出录制。拖动上方时间轴可回到任意位置接着弹，已有谱面和人声保留；按 Esc 或“收好这首”保存返回。

  4. 4
    加入人声与底奏

    录制中点击“录人声”并允许麦克风权限，即可录入自己的声音。先在线谱里编好一段声音，再在循环底奏工作台选择起止位置并“合并为循环”；原线谱不会被改动。合并后的片段可单独试听、随主线谱循环，并拥有独立的音量、混响预设和湿声控制。

声音说明

二十四张梗卡使用你提供的裁剪采样，原声加载失败时才用合成仿音兜底。“哈基米南北绿豆”现有十二段。普通乐器、鼓点与混响均由 Web Audio 在本地合成；生日快乐、小星星、虫儿飞和朋友的酒均为逐音合成谱面，不直接播放原曲。
